# Garso irasai

Greitosios frazes naudoja siuos irasus: `noriu.mp3`, `padėk.mp3`, `taip.mp3`, `ne.mp3` ir `eiti.mp3`.

Emociju korteliu MP3 irasai yra aplanke `emocijų garsai`; kortele `Nuobodžiuosi` naudoja `nuobodu.mp3`.

Asmeniniu korteliu irasus galima pasirinkti pacioje korteles kurimo formoje; jie saugomi tik irenginyje.
